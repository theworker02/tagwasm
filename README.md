# tagwasm

Tag digests and wasm fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/tagwasm/

## Install / run

```bash
git clone https://github.com/theworker02/tagwasm.git
cd tagwasm
node src/cli.js
node --test
```
